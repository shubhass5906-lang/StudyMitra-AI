\# 🎓 StudyMitra AI



\*\*StudyMitra AI\*\* is an AI-powered personalized learning assistant built with \*\*Python, Streamlit, and Google Gemini API\*\*.



It helps students learn any topic by generating simple explanations, examples, practice questions, quizzes, and quick revision notes.



\## ✨ Features



\* 📚 Enter any study topic

\* 🤖 Gemini-powered AI explanations

\* 💡 Simple beginner-friendly explanations

\* 🌍 Real-life examples

\* 💻 Technical examples when relevant

\* 📝 Practice questions

\* 🧠 Quick quizzes with answers

\* 🔄 Quick revision notes

\* 📥 Download generated study notes



\## 🛠️ Technologies Used



\* Python

\* Streamlit

\* Google Gemini API

\* Google GenAI SDK

\* python-dotenv



\## 🔑 Gemini API Integration



Google Gemini API is the core AI service used by StudyMitra AI.



The application sends the student's selected topic to Gemini and uses the generated response to create a personalized learning session.



\## 🚀 How to Run



\### 1. Clone the repository



```bash

git clone https://github.com/shubhass5906-lang/StudyMitra-AI.git

cd StudyMitra-AI

```



\### 2. Create a virtual environment



```bash

python -m venv venv

```



\### 3. Activate the environment



Windows:



```bash

venv\\Scripts\\activate

```



\### 4. Install dependencies



```bash

pip install -r requirements.txt

```



\### 5. Add your Gemini API key



Create a `.env` file:



```text

GEMINI\_API\_KEY=YOUR\_API\_KEY\_HERE

```



Never upload your `.env` file or expose your API key publicly.



\### 6. Run the application



```bash

streamlit run app.py

```
